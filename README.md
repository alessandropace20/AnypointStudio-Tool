# Integration Toolbox

A lightweight, local‑first desktop application for integration developers.

## Features (phase 1 implemented)
- **JavaFX UI** with activity bar, central workspace tabs and status bar.
- **Security utility** – password‑based AES‑GCM encryption/decryption (see `docs/SECURITY.md`).
- **Data tools** – JSON pretty‑print and basic XML pretty‑print utilities (`com.integrationtoolbox.datatools.DataTools`).
- **Modular Maven build** – root aggregator includes the legacy `configtool` module and the new `integration-toolbox` module.

## Building & Running
```bash
# Build the whole project (requires Maven 3.8+ and Java 11)
# From the repository root:
mvn clean package

# Run the application
java -jar integration-toolbox/target/integration-toolbox-0.1.0-jar-with-dependencies.jar
```

The Maven Assembly plugin bundles the JavaFX runtime, producing a self‑contained JAR (~30 MB).
